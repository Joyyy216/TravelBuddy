# Travel Buddy ✈️

Travel Buddy adalah aplikasi mobile berbasis React Native dan Expo yang membantu pengguna menemukan berbagai destinasi wisata populer, melihat detail destinasi, melakukan pencarian, serta menyimpan destinasi favorit.

## Features

- Bottom Tab Navigation (Beranda, Cari, Favorit)
- Stack Navigation (Beranda → Detail Destinasi)
- Pencarian destinasi wisata
- Detail destinasi lengkap
- Add to Favorite & Remove Favorite
- Badge jumlah favorit
- FlatList untuk menampilkan destinasi
- Route Params untuk mengirim data antar screen
- Responsive UI dengan tema biru modern
- Icon menggunakan @expo/vector-icons

## Tech Stack

- React Native
- Expo
- React Navigation
- Context API
- JavaScript
- @expo/vector-icons

## How to Run

1. Clone repository

```bash
git clone https://github.com/Joyyy216/TravelBuddy.git
```

2. Install dependencies

```bash
npm install
```

3. Jalankan aplikasi

```bash
npx expo start
```

4. Scan QR Code menggunakan Expo Go.
